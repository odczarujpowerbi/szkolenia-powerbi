# 400. OUTPUTS

## Opis folderu
Folder zawiera wygenerowane pliki HTML i TMDL gotowe do importu do Power BI.

### Pliki HTML (miary Power BI)
- Każdy plik `.html` to gotowa miara DAX zawierająca HTML
- Nazwa pliku odpowiada nazwie miary w Power BI
- Format: `nazwa = "\n<html>...</html>\n"`
- Automatyczne escapowanie cudzysłowów dla DAX

### Folder TMDL
- **_HTML.md** - plik TMDL ze wszystkimi wygenerowanymi miarami
- **_Parametr.md** - tabela kalkulowana z metadanymi miar (nazwy, kolejność)

## Import do Power BI

1. Otwórz plik `TMDL/_HTML.md`
2. Skopiuj zawartość
3. Wklej do edytora TMDL w Power BI Desktop
4. Miary zostaną automatycznie utworzone w tabeli `_HTML`
