PLAN DZIAŁAŃ

1. Użyj Prettier z konfiguracją:
   {
     "singleQuote": true,
     "semi": true,
     "trailingComma": "es5"
   }

2. Uruchom formatowanie:
   npx prettier --write "**/*.{html,css,js}"

3. Skonfiguruj ESLint enforcement:
   {
     "rules": {
       "quotes": ["error", "single", {"avoidEscape": true}]
     }
   }

4. Zcommituj zmiany:
   git add .
   git commit -m "Style: Format code with single quotes"

5. Uruchom testy:
   npm test
