# 100. RESOURCES

## Opis folderu

Folder zawiera zasoby CSS i JavaScript wykorzystywane przy generowaniu HTML dla Power BI.
Zasoby są automatycznie wczytywane przez `convert_md_to_powerbi.py` zgodnie z konfiguracją dla każdego typu treści (teoria/quiz/gaps).

## Konfiguracja

Mapowanie CSS/JS do typów treści znajduje się w pliku `config.md` w głównym katalogu projektu.
