ZAGROŻENIE #1: Data atrybuty z apostrofami

  <div data-message='John's message'></div>  BŁĄD!

ZAGROŻENIE #2: Event handlery z zagnieżdżonymi stringami
  <button onclick="alert('Hello')"></button>
  <button onclick='alert('Hello')'>  BŁĄD SKŁADNIOWY!

ZAGROŻENIE #3: JSON w HTML atrybutach
  <div data-config='{"color":"red"}'></div>  JSON wymaga "

ZAGROŻENIE #4: CSS url() z apostrofami w ścieżce
  background: url('C:\Users\John\'s Files\image.png');  BŁĄD!

ZAGROŻENIE #5: JavaScript stringi z apostrofami
  const text = 'It's working';  BŁĄD!
  const text = 'It\'s working';  OK (escapowanie)

ZAGROŻENIE #6: JSON.parse/stringify
  const json = "{'key':'value'}";  BŁĄD! JSON wymaga "
  const json = '{"key":"value"}';  OK
