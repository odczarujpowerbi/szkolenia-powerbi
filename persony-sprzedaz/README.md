# Persony sprzedażowe — Odczaruj Power BI i Clickless

Pełne definicje buyer person, pobrane ze SharePoint (site „Aplikacje Claude", `Buyer persony Odczaruj PBI/sprzedaż/skills/`), gdzie funkcjonują jako baza wiedzy dla skilli oceniających treści (landing page, oferty, maile, posty, reklamy) z perspektywy konkretnej persony.

- **[persony-odczaruj.md](./persony-odczaruj.md)** — 5 buyer person marki edukacyjnej Odczaruj Power BI (Joanna, Tomek, Zuzanna, Kasia, Paweł) + ICP/anti-ICP.
- **[persony-clickless.md](./persony-clickless.md)** — 7 buyer person konsultingu Clickless (Marek, Roman, Małgorzata, Aleksandra, Tomek, Katarzyna, Krzysztof) + ICP i case studies.

## Powiązane skille na SharePoint (nie skopiowane tu, tylko odnotowane)

Na SharePoincie te persony są opakowane jako Claude Skills wywoływane po nazwie: `persona-odczaruj-rzut-oka` (szybka opinia), `persona-odczaruj-glebia` (gruntowny feedback), `persona-odczaruj-w-skorze` (rozmowa 1:1 z jedną personą), `persona-clickless-glebia` (gruntowny feedback panelu Clickless), `clickless-oferta-jezyk-korzysci` (draft oferty/maila handlowca). Jeśli będą potrzebne jako uruchamialne skille w tym środowisku (nie tylko jako dokumenty referencyjne), trzeba je zainstalować osobno z paczek `persony-odczaruj.zip` / `sprzedaż.zip` z tego samego folderu SharePoint.
