# Budowa Gaps - Type: gaps

Szczegółowy opis budowy interaktywnych ćwiczeń typu "fill-in-the-blank" (uzupełnij luki).

## 📋 Frontmatter

```yaml
---
type: gaps
---
```

**Obowiązkowe.** Określa typ treści jako gaps.

---

## 🏗️ Struktura Pliku

### Nagłówek Zadania (`# NAZWA ZADANIA`)

```markdown
# Obliczanie Total Sales
```

**Funkcja:** Tytuł zadania wyświetlany na górze.

**Output:** Jeden plik HTML z jednym lub więcej zadań (oddzielonych `---`).

---

## 📝 Separator Zadań (`---`)

```markdown
# Zadanie 1
...treść zadania 1...

---

# Zadanie 2
...treść zadania 2...
```

**Funkcja:** Oddziela **różne zadania** w ramach jednego pliku. Każde zadanie to osobny ekran z własnym kodem i walidacją.

**Nawigacja:** Użytkownik może przechodzić między zadaniami (Previous/Next Task).

---

## 🧩 Komponenty Zadania

Każde zadanie składa się z kilku sekcji oznaczonych nagłówkami `## H2`.

### 1. Opis Zadania (Opcjonalny)

```markdown
# Obliczanie Total Sales

Stwórz miarę, która obliczy całkowitą sprzedaż bez względu na aktywne filtry.
Użyj funkcji modyfikującej kontekst oraz funkcji usuwającej filtry.
```

**Funkcja:** Kontekst i instrukcje dla użytkownika.

**Uwaga:** Tekst pomiędzy `# Tytuł` a pierwszym `##` to opis zadania.

---

### 2. Sekcja: `## Dostępne funkcje`

```markdown
## Dostępne funkcje

- SUM
- CALCULATE
- FILTER
- ALL
```

**Funkcja:** Lista funkcji, które użytkownik może **wstawić do slotów** (placeholderów).

**Format:**
- Każda funkcja w osobnej linii
- Rozpoczynaj od bullet point (`-`)
- Nazwa funkcji dokładnie jak w DAX (wielkość liter ma znaczenie)

**Przykład z większą liczbą funkcji:**
```markdown
## Dostępne funkcje

- SUM
- AVERAGE
- CALCULATE
- FILTER
- ALL
- ALLEXCEPT
- COUNTROWS
- DISTINCTCOUNT
```

---

### 3. Sekcja: `## Kod do uzupełnienia`

````markdown
## Kod do uzupełnienia

```dax
Total Sales All =
    [SLOT:0](
        SUM(Sales[Amount]),
        [SLOT:1](Sales)
    )
```
````

**Funkcja:** Kod DAX z **placeholderami `[SLOT:X]`**, które użytkownik musi wypełnić.

#### Placeholder `[SLOT:X]`

**Format:** `[SLOT:numer]`

**Numeracja:** Od 0 (zero-based indexing)
- `[SLOT:0]` - pierwszy slot
- `[SLOT:1]` - drugi slot
- `[SLOT:2]` - trzeci slot
- etc.

**Przykład z 3 slotami:**
````markdown
```dax
Sales Filter =
    [SLOT:0](
        [SLOT:1](Sales[Amount]),
        [SLOT:2](Sales, Sales[Year] = 2023)
    )
```
````

**Wynik w UI:** 3 "drop zones" lub pola wyboru, gdzie użytkownik wstawia funkcje z listy "Dostępne funkcje".

---

### 4. Sekcja: `## Poprawne rozwiązanie`

```markdown
## Poprawne rozwiązanie
CALCULATE, ALL
```

**Funkcja:** Określa **poprawną kolejność funkcji** dla slotów.

**Format:** CSV (Comma Separated Values)
- Funkcje oddzielone przecinkami
- Kolejność odpowiada numerom slotów (0, 1, 2, ...)

**Mapowanie:**
```
CALCULATE → [SLOT:0]
ALL       → [SLOT:1]
```

**Przykład z 4 slotami:**
```markdown
## Poprawne rozwiązanie
CALCULATE, SUM, FILTER, ALL
```

**Mapowanie:**
```
CALCULATE → [SLOT:0]
SUM       → [SLOT:1]
FILTER    → [SLOT:2]
ALL       → [SLOT:3]
```

---

### 5. Sekcja: `## Feedback poprawny`

```markdown
## Feedback poprawny
✅ Brawo! Poprawnie użyłeś CALCULATE z ALL.

CALCULATE modyfikuje kontekst filtra, a ALL usuwa wszystkie filtry z tabeli Sales.
Dzięki temu miara zawsze pokazuje całkowitą sprzedaż bez względu na filtry.
```

**Funkcja:** Wiadomość pokazywana po **poprawnym rozwiązaniu**.

**Formatowanie:**
- Możesz używać Markdown (bold, italic)
- Możesz używać emoji (✅, 🎉, 👍)
- Możesz używać `inline code`

---

### 6. Sekcja: `## Feedback niepoprawny` (Opcjonalna, Wielokrotna)

```markdown
## Feedback niepoprawny: SUM, FILTER
❌ SUM nie modyfikuje kontekstu.

Potrzebujesz funkcji, która może zmieniać kontekst filtra podczas obliczania.

## Feedback niepoprawny: ALL, CALCULATE
❌ Kolejność jest niepoprawna.

CALCULATE powinno być funkcją zewnętrzną, a ALL wewnątrz jako argument.

## Feedback niepoprawny: FILTER, ALL
❌ FILTER dodaje warunek, nie usuwa filtrów.

Spróbuj funkcji, która usuwa filtry zamiast je dodawać.
```

**Funkcja:** Kontekstowy feedback dla **konkretnych błędnych kombinacji**.

**Format:** `## Feedback niepoprawny: ODPOWIEDŹ_SLOT_0, ODPOWIEDŹ_SLOT_1, ...`

**Przykład z 3 slotami:**
```markdown
## Feedback niepoprawny: CALCULATE, AVERAGE, FILTER
❌ AVERAGE nie jest właściwe w tym kontekście.

Używamy SUM do sumowania wartości, nie AVERAGE do średniej.
```

**Mapowanie:**
- `CALCULATE` → to co użytkownik wstawił w `[SLOT:0]`
- `AVERAGE` → to co użytkownik wstawił w `[SLOT:1]`
- `FILTER` → to co użytkownik wstawił w `[SLOT:2]`

**Uwaga:** Możesz mieć **wiele sekcji** feedback niepoprawny dla różnych kombinacji błędów.

---

### 7. Sekcja: `## Wskazówka` (Opcjonalna)

```markdown
## Wskazówka
Pomyśl o funkcji, która może usuwać filtry z kontekstu.
Pierwsza funkcja powinna modyfikować kontekst obliczenia.
```

**Funkcja:** Przycisk "Hint" w UI pokazujący podpowiedź.

**Kiedy używać:**
- Trudne zadania
- Gdy użytkownik może się zablokować
- Dla wsparcia początkujących

---

## 📖 Przykład Kompletnego Gaps

```markdown
---
type: gaps
---

# Obliczanie Total Sales bez filtrów

Stwórz miarę, która obliczy całkowitą sprzedaż **bez względu na aktywne filtry**.
Użyj funkcji modyfikującej kontekst oraz funkcji usuwającej filtry.

## Dostępne funkcje

- SUM
- CALCULATE
- FILTER
- ALL

## Kod do uzupełnienia

```dax
Total Sales All =
    [SLOT:0](
        SUM(Sales[Amount]),
        [SLOT:1](Sales)
    )
```

## Poprawne rozwiązanie
CALCULATE, ALL

## Feedback poprawny
✅ Świetnie! Użyłeś **CALCULATE** z **ALL**.

CALCULATE modyfikuje kontekst obliczenia, a ALL usuwa wszystkie filtry z tabeli Sales.
Dzięki temu miara zawsze pokazuje **całkowitą sprzedaż**, niezależnie od tego jakie filtry są aktywne na dashboardzie.

## Feedback niepoprawny: SUM, FILTER
❌ SUM jest już użyte wewnątrz wyrażenia.

Potrzebujesz funkcji, która **modyfikuje kontekst filtra** jako funkcja zewnętrzna.

## Feedback niepoprawny: CALCULATE, FILTER
❌ FILTER **dodaje** warunek filtrowania, nie usuwa filtrów.

W tym zadaniu chcemy **usunąć wszystkie filtry**, nie dodawać nowe. Spróbuj innej funkcji.

## Feedback niepoprawny: FILTER, ALL
❌ FILTER nie jest właściwą funkcją zewnętrzną.

Aby modyfikować kontekst, użyj funkcji **CALCULATE** jako funkcji zewnętrznej.

## Wskazówka
Pierwsza funkcja powinna **modyfikować kontekst** (jedna z najważniejszych funkcji w DAX).
Druga funkcja powinna **usuwać filtry** z tabeli.

---

# Filtrowanie sprzedaży po roku

Stwórz miarę pokazującą sprzedaż **tylko z roku 2023**.
Użyj funkcji modyfikującej kontekst oraz funkcji filtrującej.

## Dostępne funkcje

- CALCULATE
- FILTER
- ALL
- YEAR

## Kod do uzupełnienia

```dax
Sales 2023 =
    [SLOT:0](
        SUM(Sales[Amount]),
        [SLOT:1](Sales, YEAR(Sales[Date]) = 2023)
    )
```

## Poprawne rozwiązanie
CALCULATE, FILTER

## Feedback poprawny
✅ Brawo! **CALCULATE** z **FILTER** to świetne połączenie.

FILTER tworzy tabelę zawierającą tylko wiersze, które spełniają warunek `YEAR(Sales[Date]) = 2023`.
CALCULATE używa tej przefiltrowanej tabeli jako kontekstu do obliczenia sumy.

## Feedback niepoprawny: CALCULATE, ALL
❌ ALL usuwa filtry, a my chcemy **dodać** filtr na rok 2023.

Użyj funkcji, która może **filtrować** tabelę według warunku.

## Feedback niepoprawny: FILTER, CALCULATE
❌ Kolejność jest niepoprawna.

CALCULATE powinno być **funkcją zewnętrzną**, która modyfikuje kontekst.

## Wskazówka
Potrzebujesz funkcji, która może stworzyć tabelę zawierającą tylko wiersze spełniające warunek.
```

**Output:**
- `Gaps - Ćwiczenia DAX.html`
- 2 zadania z nawigacją (Previous Task / Next Task)
- Interaktywne sloty do wypełnienia
- Walidacja w czasie rzeczywistym
- Kontekstowe feedbacki dla błędów
- Przyciski "Hint" dla wskazówek

## 🎯 Specjalne Przypadki

### Gaps z Jednym Slotem

```markdown
# Prosta Miara

Uzupełnij nazwę funkcji sumującej:

## Dostępne funkcje

- SUM
- AVERAGE
- COUNT

## Kod do uzupełnienia

```dax
Total = [SLOT:0](Sales[Amount])
```

## Poprawne rozwiązanie
SUM

## Feedback poprawny
✅ Poprawnie! SUM sumuje wartości w kolumnie.
```

### Gaps z Wieloma Slotami

```markdown
# Zaawansowane CALCULATE

## Dostępne funkcje

- CALCULATE
- SUM
- FILTER
- ALL
- Sales
- Product

## Kod do uzupełnienia

```dax
Complex Measure =
    [SLOT:0](
        [SLOT:1]([SLOT:2][Amount]),
        [SLOT:3]([SLOT:4], [SLOT:5][Category] = "Electronics")
    )
```

## Poprawne rozwiązanie
CALCULATE, SUM, Sales, FILTER, Product, Product
```

**Mapowanie:**
- SLOT:0 → CALCULATE
- SLOT:1 → SUM
- SLOT:2 → Sales (tabela)
- SLOT:3 → FILTER
- SLOT:4 → Product (tabela)
- SLOT:5 → Product (tabela)

### Gaps z Kodem Wyjaśniającym w Feedbacku

````markdown
## Feedback poprawny
✅ Brawo! Poprawne rozwiązanie.

Twój kod teraz wygląda tak:
```dax
Total Sales All =
    CALCULATE(
        SUM(Sales[Amount]),
        ALL(Sales)
    )
```

To usunie wszystkie filtry z tabeli Sales.
````

## 💡 Wskazówki i Best Practices

### ✅ DO (Rób tak)

1. **Jasne instrukcje:**
   ```markdown
   Stwórz miarę obliczającą sprzedaż z 2023 roku.
   ```

2. **Odpowiednia liczba slotów:**
   - 2-3 sloty: ✅ Optymalne
   - 4-5 slotów: ⚠️ Średnio trudne
   - 6+: ❌ Za trudne

3. **Funkcje logicznie powiązane:**
   ```markdown
   ## Dostępne funkcje
   - CALCULATE
   - FILTER
   - ALL
   ```
   (wszystkie związane z kontekstem)

4. **Kontekstowy feedback:**
   ```markdown
   ## Feedback niepoprawny: FILTER, ALL
   ❌ FILTER nie jest zewnętrzną funkcją kontekstu.
   ```

5. **Wskazówki dla trudnych zadań:**
   ```markdown
   ## Wskazówka
   Pomyśl o funkcjach Time Intelligence.
   ```

### ❌ DON'T (Nie rób tego)

1. **Za dużo funkcji do wyboru:**
   ```markdown
   ## Dostępne funkcje
   - SUM
   - AVERAGE
   - COUNT
   - CALCULATE
   - FILTER
   - ALL
   - ALLEXCEPT
   - REMOVEFILTERS
   - ... (20 więcej)  ← Za dużo!
   ```

2. **Niejasne sloty:**
   ```markdown
   ## Kod do uzupełnienia
   ```dax
   Miara = [SLOT:0]  ← Co tu ma być?
   ```
   ```

3. **Brak feedbacku dla popularnych błędów:**
   ```markdown
   (tylko feedback poprawny, brak feedback niepoprawny)
   ← Użytkownik nie wie co źle
   ```

4. **Błędna kolejność w rozwiązaniu:**
   ```markdown
   ## Kod do uzupełnienia
   ```dax
   M = [SLOT:0]([SLOT:1])
   ```

   ## Poprawne rozwiązanie
   FUNC2, FUNC1  ← Czy na pewno? (FUNC2 → SLOT:0?)
   ```

5. **Za długi kod:**
   ````markdown
   ```dax
   Very Long Measure =
       VAR Step1 = [SLOT:0](...)
       VAR Step2 = [SLOT:1](...)
       VAR Step3 = [SLOT:2](...)
       ... (20 linii)  ← Za skomplikowane
   ```
   ````

## 🔍 Debugowanie Problemów

### Problem: "Walidacja zawsze pokazuje błąd"

**Przyczyna:** Wielkość liter w rozwiązaniu nie zgadza się z dostępnymi funkcjami
```markdown
## Dostępne funkcje
- CALCULATE  ← Uppercase

## Poprawne rozwiązanie
calculate  ← Lowercase (ZŁE!)
```

**Rozwiązanie:** Użyj dokładnie tej samej wielkości liter
```markdown
## Poprawne rozwiązanie
CALCULATE  ← DOBRE
```

### Problem: "Slot nie wyświetla się"

**Przyczyna:** Błędny format placeholdera
```markdown
[SLOT 0]  ← Spacja zamiast dwukropka (ZŁE)
[SLOT-0]  ← Myślnik zamiast dwukropka (ZŁE)
{SLOT:0}  ← Klamry zamiast nawiasów (ZŁE)
```

**Rozwiązanie:**
```markdown
[SLOT:0]  ← DOBRE
```

### Problem: "Feedback niepoprawny nie wyświetla się"

**Przyczyna:** Błędny format nagłówka
```markdown
## Feedback niepoprawny SUM, FILTER  ← Brak dwukropka (ZŁE)
## Niepoprawny feedback: SUM, FILTER  ← Zła kolejność (ZŁE)
```

**Rozwiązanie:**
```markdown
## Feedback niepoprawny: SUM, FILTER  ← DOBRE
```

### Problem: "Liczba funkcji w rozwiązaniu nie zgadza się z slotami"

**Przyczyna:**
```markdown
```dax
M = [SLOT:0]([SLOT:1])  ← 2 sloty
```

## Poprawne rozwiązanie
CALCULATE  ← Tylko 1 funkcja (ZŁE!)
```

**Rozwiązanie:**
```markdown
## Poprawne rozwiązanie
CALCULATE, ALL  ← 2 funkcje dla 2 slotów (DOBRE)
```

## 📊 Cheat Sheet - Gaps

| Element | Składnia | Funkcja | Wymagane |
|---------|----------|---------|----------|
| **Frontmatter** | `type: gaps` | Określa typ | ✅ TAK |
| **Tytuł** | `# Nazwa Zadania` | Nagłówek | ✅ TAK |
| **Separator zadań** | `---` | Oddziela zadania | ⚠️ Jeśli >1 zadanie |
| **Dostępne funkcje** | `## Dostępne funkcje` | Lista opcji | ✅ TAK |
| **Kod** | `## Kod do uzupełnienia` | DAX z `[SLOT:X]` | ✅ TAK |
| **Placeholder** | `[SLOT:0]` | Miejsce na funkcję | ✅ TAK |
| **Rozwiązanie** | `## Poprawne rozwiązanie` | CSV poprawnych funkcji | ✅ TAK |
| **Feedback OK** | `## Feedback poprawny` | Wiadomość sukcesu | ✅ TAK |
| **Feedback błąd** | `## Feedback niepoprawny: ...` | Kontekstowy błąd | ⚠️ Opcjonalne |
| **Wskazówka** | `## Wskazówka` | Hint dla użytkownika | ⚠️ Opcjonalne |
